CounterPro Inventory Sync

Once a day this reads the Moraware inventory view for each location that is switched on, using the Moraware sign-in already in this browser, and saves the slab list where CounterPro reads it. No Moraware password is stored.

Locations

Tick a location to include it and paste the address of its Moraware inventory view. A location that is not ticked is left out of CounterPro at the next sync.

Where the inventory is saved

Schedule

The token is kept in this browser's extension storage on this computer. Chrome has to be open at the sync time; if it was closed, the sync runs the next time Chrome starts.
