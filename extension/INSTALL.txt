CounterPro Inventory Sync - how to install

1. Unzip this folder somewhere it can stay (for example Documents).
   Chrome reads the extension from this folder every time it starts,
   so do not delete or move it afterwards.
2. In Chrome open  chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and choose this folder
   (the one that contains manifest.json).
5. Click the extension's icon (puzzle piece, then "CounterPro Inventory
   Sync"), then "Options".
6. Under "Locations", tick each location you want in CounterPro and
   paste the address of its Moraware inventory view. Vernon and
   Abbotsford are filled in already. Leave a location unticked to keep
   it out of CounterPro; its address stays saved for later.
   Then paste the GitHub token and click "Save options".
   The repository is already filled in: stillbeau/counterpro-data
7. Make sure you are signed in to Moraware in this Chrome.
8. Click the extension's icon and press "Sync now".
   It should say "Sent N slabs" and list each Moraware view.

After that it syncs by itself once a day while Chrome is open.
If a sync fails, the icon shows a red "!" and the popup says why.

Updating to a newer version
---------------------------
1. Copy the new files over the old ones in the SAME folder you loaded
   before (the one that contains manifest.json). Keeping the same folder
   keeps your saved token.
2. In chrome://extensions click the round reload arrow on the
   "CounterPro Inventory Sync" card. The version number should change.
3. Press "Sync now" again.

What to expect during a sync
----------------------------
If Moraware's page needs the browser to finish drawing the slab table,
the extension opens the view in a background tab for a few seconds and
closes it again. That is normal.
